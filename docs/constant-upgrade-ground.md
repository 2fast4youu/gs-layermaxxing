APK82 adds support for declared placement rule8 while retaining exact historic2–7 logic and default7 constructors. Server default7 remains unchanged. A dedicated test deployment may explicitly set `GS_ISLAND_GRID_VERSION=8`; only exact7/8 are accepted, invalid configuration fails before database initialization. Deliver a compatible APK before enabling8.

Rule8 reserves each building's own stage0 ground on each land stage for every upgrade0–3. The shared deterministic `server/app/geometry/island_constant_ground.json` is generated by `python server/tools/island_constant_ground.py` and packaged directly into Android resources. Artwork sizes, decoration, terrain and historic fixtures are unchanged. Same-position upgrades preserve saved positions/neighbours, including legacy invalid layouts. New placements and moves still validate terrain, occupied cells and lighthouse coast contact. No automatic cleanup, displacement, payment reconstruction or refunds. Normal costs remain exactly once; creative upgrades preserve spent. Harbour socket/berth follows the declared contract.

Native UI tests verify POST/LIGHTHOUSE0→3, creative/normal balances, exact neighbours/revisions, cancellation and guarded moves with independent injected writer/oracle. Backend tests cover all buildings/lands, configuration and7→8 restart preservation.

Postal identity lettering now uses Android casual handwriting in warm ink directly on original painted envelopes.
